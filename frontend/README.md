# Frontend

This directory contains the Next.js application for the NLH training
simulator.  In milestone M0 the frontend is a thin shell with two
pages: a **Table** stub (the default route) and a **Settings**
placeholder.  Both pages are implemented in TypeScript and styled
with Tailwind CSS.  You can start the development server via:

```bash
npm install
npm run dev
```

In later milestones the UI will expose the full poker table, allow
humans to act, configure bots and ranges, and export hand histories.
